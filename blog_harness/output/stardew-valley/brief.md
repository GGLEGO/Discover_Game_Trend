# 브리프: Stardew Valley

- 게임명(정식 표기): Stardew Valley (스타듀 밸리)
- 스팀 상점 주소: https://store.steampowered.com/app/413150/Stardew_Valley/
- 글의 방향: 지금 구매를 고민하는 사람을 위한 종합 리뷰
- 예상 독자: 스타듀 밸리를 아직 해 보지 않았거나, 이름만 들어 본 스팀 이용자
- 꼭 다룰 것: 어떤 게임인지(플레이 방식), 장점과 단점, 가격과 사양, 한국어 지원, 멀티플레이, 최근 업데이트 상황, 추천 대상
- 다루지 않을 것: 공략(작물 수익 계산, 호감도 선물 표 등), 모드 설치법, 스토리 스포일러
- 분량 목표: 2,000~3,000자
- 사용자 추가 요청: 없음
